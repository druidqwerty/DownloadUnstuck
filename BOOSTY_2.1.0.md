---

**Download Unstuck 2.1.0** is out as a test version.

The Java part now has a **Player-save network buffer** option for heavily modded hosted servers: **64 MB by default**, adjustable from 2 to 1024 MB. It raises both the local player-save and network-character limits, helping with huge modded inventories and player mod data.

This is not a bandwidth or Steam-speed setting. It requires ZombieBuddy and applies on the next server launch. Compatibility hashes now protect all three replaced game classes.

Java simulation, class-path SelfTest and all 15 Lua scenarios pass. A live hosting session on 2.1.0 has not been run yet — please test and send `Zomboid/console.txt` and `coop-console.txt` if something goes wrong.

Вышла тестовая версия **Download Unstuck 2.1.0**.

В Java-части появилась настройка **«Сетевой буфер сохранения игрока»** для сильно модифицированных своих серверов: **64 МБ по умолчанию**, можно выбрать от 2 до 1024 МБ. Увеличены ограничения и локального сохранения, и сетевых данных персонажа — это помогает при огромных инвентарях и большом объёме данных модов.

Настройка не увеличивает скорость сети или загрузки из Steam. Требуется ZombieBuddy; применяется при следующем запуске сервера. Проверки совместимости SHA-256 теперь покрывают все три заменяемых класса игры.

Java-симуляция, SelfTest и все 15 Lua-сценариев пройдены. Живой запуск сервера на 2.1.0 ещё не проводился — тестируйте и присылайте `Zomboid/console.txt` и `coop-console.txt` при проблемах.
